Atribuições e Referências

Esta página apresenta informações sobre o desenvolvimento do projeto iGaming Insights Brasil e as fontes de referência relacionadas ao conteúdo.

Desenvolvimento do projeto

O iGaming Insights Brasil foi desenvolvido por José Leandro da Silva Moura como projeto educacional da disciplina WDD231 - Desenvolvimento Web Frontend I.

O site utiliza HTML, CSS e JavaScript para apresentar informações educativas sobre apostas esportivas, cassino online, regulamentação e gestão de risco.

O projeto também utiliza dados em formato JSON para apresentar modalidades esportivas de maneira dinâmica.

Referências de conteúdo

As instituições e os materiais abaixo são referências relevantes para consulta sobre o mercado brasileiro de apostas, regulamentação e desenvolvimento web.

  • Ministério da Fazenda - Informações institucionais sobre o setor de apostas.
  • Lei nº 14.790/2023 - Legislação brasileira sobre apostas de quota fixa.
  • MDN Web Docs - Documentação de HTML, CSS e JavaScript.
  • web.dev - Boas práticas de desempenho, acessibilidade e desenvolvimento web.

Recursos visuais

O projeto utiliza elementos visuais desenvolvidos com CSS, caracteres Unicode e emojis para representar as áreas apresentadas.

O favicon iG utiliza as cores da identidade visual do site.

Finalidade educacional

O iGaming Insights Brasil possui finalidade exclusivamente informativa e educacional.

O conteúdo não representa recomendação de apostas, promessa de ganhos ou aconselhamento financeiro.
